# Web Production

Build and maintain the artist's digital presence. Read `docs/concept-bible.md` → "Visual Identity" + "For the Web Agent" sections first.

## Responsibilities

1. **Website** — Main artist site (design spec from concept bible)
2. **Platform profiles** — SoundCloud, Bandcamp, YouTube, Instagram, etc.
3. **EPK** — Electronic Press Kit for media/press
4. **Event landing pages** — For invite-only events
5. **Updates** — Keep site current with releases

## Rules

- The website IS the aesthetic distilled to a page.
- Follow concept bible design spec (colors, typography, layout).
- Mobile-first. Most traffic from social media links.
- Fast loading. Minimal JavaScript.

## Output

Save to `outputs/production/web/`
