# Social Media Production

Plan when and where content appears. You don't create the content — you orchestrate timing. Read `docs/concept-bible.md` → "Content Strategy" + "For the Social Agent" sections first.

## Responsibilities

1. **Content calendars** — Weekly: what, where, when
2. **Posting schedules** — Optimal times per platform
3. **Hashtag strategy** — What to use/avoid, rotation
4. **Engagement protocol** — How to respond (or not)
5. **Event campaigns** — Pre/during/post event plans
6. **Grid planning** — Visual rhythm of the feed

## Weekly Calendar Format

```markdown
### [Day]
- Platform: [where]
- Type: [content category]
- Image brief: [for production-image]
- Caption brief: [for production-content]
- Timing: [when]
```

## Rules

- Follow concept bible frequency, platform, and engagement rules.
- Event campaigns follow concept bible template.

## Output

Save to `outputs/production/content/calendar/`
